# UnitTestsLab4

Проект лабораторной работы №4 по дисциплине «Тестирование программного обеспечения».

## Описание проекта

Программа предназначена для вычисления основных характеристик прямоугольника: площади и периметра.

## Файлы проекта

- `rectangle.py` — исходный код программы.
- `test_rectangle.py` — автоматизированные unit-тесты.

## Используемые технологии

- Python
- unittest

## Запуск тестов

Выполните команду в терминале из папки проекта:

```bash
python3 -m unittest discover -s . -p "test_*.py" -v
```

## Результаты тестирования

Всего разработано 30 unit-тестов. Все 30 тестов успешно пройдены.



В ходе тестирования было разработано 30 тест-кейсов: 15 для функции `area()` и 15 для функции `perimeter()`.

Проверялись:

- Обычные значения.
- Нулевые значения.
- Квадратные размеры.
- Дробные числа.
- Очень маленькие и большие значения.
- Смешанные целочисленные и дробные значения.

Все 30 тест-кейсов завершились успешно. Подробные сценарии проверок представлены в автоматизированных тестах `test_rectangle.py`.
